## Notas

- Los nombres de test son los métodos de `tests/`; la clase indica el fichero (`tests/**/<Clase>.cs`).
- VAL-010 entre plataformas (Linux frente a Windows) no se afirma: la CI ejecuta la suite en las dos, pero no compara resultados entre ellas.
- El modo `EnableValidation = false` desactiva VAL-001..005 por tick. El juego, el CLI y los benchmarks usan `true`.
